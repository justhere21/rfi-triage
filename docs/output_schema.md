## What comes out

For each item, the agent gives us:

- **item_id**: same name as the input
- **needs_response**: does someone need to answer it?
- **respond_from**: who should answer
- **due_by**: the date it's needed by
- **contract_risk**: how risky it is for the contract
- **flags**: any problems it found, with the reason and proof for each
- **human_review_required**: always yes, because a person makes the final call and the agent only suggests
