## What goes in

Each item is one RFI, email, or set of meeting minutes. For each one we keep:

- **item_id**: its name, like RFI-014
- **item_type**: rfi, email, or minutes
- **provenance**: where it came from (synthetic, observed_public, or partner)
- **submitted_date**: when it was sent
- **submitted_by**: who sent it
- **discipline**: the trade, like mechanical or electrical
- **location**: where on the project (leave blank if it doesn't say)
- **question_text**: the whole message
- **drawing_refs**: drawing numbers it mentions (empty if none)
- **spec_refs**: spec sections it mentions (empty if none)
- **attachments**: files attached (empty if none)
- **related_item_ids**: earlier messages it mentions
